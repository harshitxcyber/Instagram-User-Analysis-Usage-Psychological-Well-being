# Instagram User Analysis – Usage & Psychological Well-being

## Project Overview

Conducted an extensive data analysis of 99,999 Instagram users to investigate the relationship between social media usage patterns and psychological well-being. Analysed 56 variables and developed 30+ visualizations to identify patterns in user behaviour, stress levels, and happiness scores.

## Key Findings

- Identified a strong positive correlation (r = 0.83) between daily Instagram usage and stress levels.
- Found that excessive screen time and reel consumption were associated with increased stress and anxiety indicators.
- Discovered that moderate social media usage was associated with higher happiness levels.
- Observed that higher engagement metrics do not necessarily translate into better psychological well-being.
- Examined relationships between usage duration, user engagement, stress, and happiness.

## Tools & Technologies

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Exploratory Data Analysis (EDA)
- Statistical Analysis
- Data Visualization

## Business Recommendations

1. **Usage Control Features:** Introduce screen-time limits and personalized usage reminders.
2. **Ethical Algorithm Design:** Promote healthier content recommendations rather than maximizing screen time alone.
3. **Mental Health Tracking:** Integrate well-being indicators and digital wellness features.
4. **Responsible Engagement:** Encourage balanced social media consumption.

## Project Impact

The analysis provides data-driven insights into the relationship between Instagram usage and psychological well-being. It highlights opportunities for social media platforms to balance user engagement with digital wellness and responsible platform design.

*Note: The findings represent statistical associations and should not be interpreted as proof of causation.*
